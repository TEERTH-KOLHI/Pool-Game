# Classic Pool Game

A classic 8-ball pool game built with HTML5 Canvas and JavaScript. Play against a friend locally or challenge the AI with various difficulty levels.

---

### Features
* **Game Modes**: 2 Players (Local) or 1 Player vs Computer AI.
* **AI Difficulty**: Easy, Medium, Hard, and Insane.
* **Controls**: Intuitive mouse aiming and keyboard power adjustment.

### Controls:
* **Mouse**: Aim by moving the mouse. Left click to shoot.
* **'W'**: Increase shot power.
* **'S'**: Decrease shot power.
* **'Esc'**: Return to main menu.
